# md2any UI 设计文档

## 设计目标

md2any 是一个工具型 Windows 桌面软件。UI 应清晰、直接、稳定，优先服务高频转换流程，不做营销式页面和复杂装饰。

设计原则：

- MVP 采用单窗口主界面
- QML 负责界面，C++ 后端负责业务逻辑
- 表单、按钮、日志和状态区域布局清楚
- 错误信息尽量就近展示，转换详情进入日志区域
- 保留后续扩展设置页、历史记录和批量转换的空间

## 页面结构

### 主窗口

主窗口包含：

- 顶部状态区
- 文件选择区
- 转换配置区
- 操作按钮区
- 状态和日志区

推荐默认尺寸：

- 默认窗口：`900 x 620`
- 最小窗口：`760 x 520`

布局草图：

```text
-------------------------------------------------
| md2any                          Pandoc: 已检测 |
-------------------------------------------------
| 输入文件  [路径输入框................] [选择] |
| 输出文件  [路径输入框................] [选择] |
-------------------------------------------------
| 输出格式  [html/docx/pdf v]                    |
| [ ] 覆盖已存在文件                             |
-------------------------------------------------
| [开始转换] [取消]                              |
-------------------------------------------------
| 状态：等待操作                                  |
| 日志：                                          |
| --------------------------------------------- |
| 转换日志会显示在这里                            |
-------------------------------------------------
```

### 设置弹窗

MVP 可暂不实现完整设置弹窗。若开发过程中需要配置 Pandoc 路径，可采用轻量弹窗：

- Pandoc 路径输入框
- 自动检测按钮
- 保存按钮
- 取消按钮

## 主要组件

### 顶部状态区

组件：

- 应用名称 Label
- Pandoc 状态 Label

状态：

- `Pandoc: 检测中`
- `Pandoc: 已检测`
- `Pandoc: 未检测`

### 文件路径输入

组件：

- `TextField`
- `Button`
- `FileDialog`

行为：

- 输入文件支持手动输入和文件选择器选择
- 输出文件支持手动输入和保存文件选择器选择
- 输入文件变化后，若输出路径为空，自动生成默认输出路径
- 输出格式变化后，自动更新输出扩展名

### 输出格式选择

组件：

- `ComboBox`

MVP 输出格式：

- `html`
- `docx`
- `pdf`

说明：

- HTML 和 DOCX 是首批验证重点
- PDF 依赖用户本机 Pandoc PDF 环境，失败时显示 Pandoc 错误

### 操作按钮

组件：

- `Button`

按钮：

- 开始转换
- 取消

取消按钮在转换中可用，后端通过 `QProcess` 取消当前转换。

### 状态和日志区域

组件：

- `Label`
- `TextArea`
- 可选 `ProgressBar`

要求：

- 日志只读
- 每次转换前清空上一次日志
- 转换成功时显示输出路径
- 转换失败时显示错误详情
- 日志区域使用等宽字体

## 交互流程

### 正常转换

1. 用户选择输入文件。
2. 系统生成默认输出路径。
3. 用户选择输出格式。
4. 用户点击开始转换。
5. UI 禁用输入控件和开始按钮。
6. 状态显示 `转换中...`。
7. 后端调用 Pandoc。
8. 转换成功后状态显示 `转换成功`。
9. 日志显示输出文件路径和 Pandoc 输出。
10. UI 恢复可编辑状态。

### Pandoc 未检测到

1. 应用启动时检测 Pandoc。
2. 未检测到时顶部显示 `Pandoc: 未检测`。
3. 用户点击开始转换后，状态显示失败。
4. 日志区域提示安装 Pandoc 或配置 Pandoc 路径。

### 转换失败

1. Pandoc 返回非零退出码或后端校验失败。
2. 状态显示 `转换失败`。
3. 日志区域显示错误详情。
4. 保留用户输入，方便修改后重试。

## 空状态

### 初始状态

- 输入文件为空
- 输出文件为空
- 输出格式默认为 `html`
- 状态显示 `请选择输入文件`
- 日志区域显示 `转换日志会显示在这里`

### 日志为空

不使用复杂插图，只显示浅色占位文本。

## 错误状态

需要覆盖：

- 未选择输入文件
- 输入文件不存在
- 输出路径为空
- 输出目录不存在
- 输出文件已存在且未勾选覆盖
- Pandoc 未安装或路径无效
- Pandoc 执行失败
- PDF 转换环境缺失

展示规则：

- 表单级错误显示在状态区
- Pandoc 详细错误显示在日志区
- 不对每个错误都弹窗，避免打断用户修正

## 加载状态

转换中：

- 开始转换按钮禁用
- 文件选择、格式选择、覆盖选项禁用
- 状态显示 `转换中...`
- 可显示不确定进度条

Pandoc 检测中：

- 顶部状态显示 `Pandoc: 检测中`

## UI 风格建议

- 使用 Qt Quick Controls 2
- 偏工具软件风格
- 背景使用浅灰或系统默认色
- 主色使用稳重蓝色
- 控件间距一致
- 不使用复杂动画
- 不使用大面积装饰图形
- 按钮高度 `32px - 36px`
- 主窗口边距 `16px`
- 表单行间距 `10px - 12px`
- 区块间距 `16px`
- 错误状态使用红色
- 成功状态使用绿色
- 警告状态使用橙色
