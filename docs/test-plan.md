# md2any 测试计划

## 测试目标

确保 md2any 可以在 Windows 环境下稳定运行，能够通过 QML 图形界面调用 Pandoc 完成 Markdown 文件转换，并具备基本错误处理、自动化测试和打包后验证能力。

## 测试策略

### 核心逻辑测试

优先覆盖不依赖 QML、不启动 GUI 的 C++ 后端逻辑：

- 转换任务模型
- 输出格式校验
- Pandoc 命令构建
- 输入输出路径校验
- Pandoc 执行结果解析
- 配置读写

这部分应作为第一批自动化测试。

### 集成测试

在本机安装 Pandoc 的环境中执行：

- Markdown 转 HTML
- Markdown 转 DOCX
- Markdown 转 PDF
- 中文路径
- 带空格路径

集成测试可以先作为手动验证或可选 CTest 测试，避免没有 Pandoc 的环境全部失败。

### UI 冒烟测试

MVP 阶段先做轻量验证：

- QML 页面可加载
- 主窗口可启动
- 核心控件存在
- 点击转换按钮能触发后端
- 错误信息能显示在状态和日志区域

后续再考虑引入更细的 Qt/QML 自动化测试。

## 测试范围

### 数据新增

MVP 不涉及复杂业务数据新增。需要验证用户选择输入文件、输出路径和输出格式后，应用能创建一次转换任务。

### 数据编辑

需要验证用户修改以下字段后，转换任务同步更新：

- 输入文件路径
- 输出文件路径
- 输出格式
- 是否覆盖已存在文件

### 数据删除

MVP 不主动删除用户文件。需要验证：

- 转换不会删除源文件
- 输出文件已存在且未允许覆盖时不会静默覆盖
- 允许覆盖时行为明确

### 搜索筛选

搜索和筛选属于非 MVP。后续加入历史记录后再测试：

- 历史任务搜索
- 按格式筛选
- 按成功或失败状态筛选

### 文件保存和读取

测试项：

- 读取存在的 `.md` 文件
- 处理不存在的输入文件
- 处理空 Markdown 文件
- 处理中文文件名
- 处理带空格路径
- 输出到存在目录
- 输出到不存在目录
- 输出文件已存在时的行为
- 转换成功后目标文件真实生成

### 错误输入

测试项：

- 未选择输入文件
- 未选择输出路径
- 未选择输出格式
- 输入文件不存在
- 输出目录不存在
- 输出格式不支持
- Pandoc 未安装
- Pandoc 路径配置错误
- Pandoc 返回非零退出码
- 输出目录无权限

### 空数据状态

测试项：

- 首次启动没有历史数据时不报错
- 未选择文件时界面显示空状态
- 转换日志为空时不报错
- 没有 Pandoc 配置时显示明确提示

### 打包后运行

测试项：

- 打包后的 exe 能启动
- QML 资源能正确加载
- 应用能找到系统 Pandoc 或提示未安装
- 转换功能在打包版本中可用
- 资源路径和相对路径不失效

## 手动验收用例

### 正常转换

1. 准备一个 `sample.md`。
2. 启动应用。
3. 选择 `sample.md`。
4. 选择输出格式 `html`。
5. 设置输出路径。
6. 点击开始转换。
7. 确认生成目标文件。
8. 确认状态显示转换成功。

### Pandoc 未安装

1. 在没有 Pandoc 的环境中启动应用，或配置错误 Pandoc 路径。
2. 点击开始转换。
3. 确认 UI 显示 Pandoc 不可用。
4. 确认日志说明安装或配置 Pandoc。

### PDF 转换失败

1. 选择 Markdown 文件。
2. 输出格式选择 `pdf`。
3. 在缺少 PDF 引擎的环境中转换。
4. 确认 UI 显示转换失败。
5. 确认日志保留 Pandoc 错误详情。

### 输出文件已存在

1. 设置一个已存在的输出文件路径。
2. 不勾选覆盖。
3. 点击开始转换。
4. 确认转换被阻止。
5. 勾选覆盖后重试。

## 代码审查重点

- QML 是否直接拼接 Pandoc 命令
- Pandoc 调用是否集中在后端模块
- 是否绕过 `QProcess` 直接拼接 shell 命令
- 是否正确处理 Windows 路径
- 是否保留 Pandoc stderr
- 是否有未处理异常
- 错误信息是否对用户可理解
- 是否存在重复校验逻辑
- 是否引入了超出 MVP 的复杂设计
- QML 资源路径是否支持打包后运行
- 测试是否依赖真实 Pandoc

## 打包验证清单

- 执行测试通过
- 生成 exe
- exe 可以启动
- QML 页面加载正常
- HTML 转换可用
- Pandoc 不存在时提示明确
- 中文路径转换不报路径错误
- 带空格路径转换不报路径错误
- README 中的运行、测试、打包命令准确
